## Scope

The checks cover browser composition, real HTTP submission, private receipts, manual moment declaration, canonical reveal, the public archive, hold/reject review, simulated prices, the wrap-up reel, and mocked Extension authorization/context/broadcast lifecycle. The screenshot fixtures include four category colors and the CALLED IT verdict. The configuration captures show saved clip/chat toggles and activity thresholds. A saved stream-timer minute is also checked.

The condition-matching test injects an enabled fake compiler that returns a third-occurrence Margit condition. It verifies the UI result, unchanged wallet and notes, and the absence of quote/seal requests. This is a fixture test, not proof that Codex ran a runtime compilation. No compiler child process is started.

Twitch Hosted Test, real Extension PubSub delivery, live Decisions judgements, an OBS Browser Source, real viewer latency, and a live broadcast remain unverified. The demonstrated prediction verdict and moderation marker are deterministic demo fixtures.
