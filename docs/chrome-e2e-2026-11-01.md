## Real Hosted Test bootstrap repair

Sealed Notes was installed as the new Panel 1. The existing WarioStream Video Overlay 1 was left unchanged.

Initially the Twitch supervisor kept the extension iframe at `display:none`. The panel, configuration page and popout were blank. Inspection of the public Twitch helper version `1.28.0` found that its bootstrap registers a `DOMContentLoaded` listener. Loading the helper dynamically after that event misses the handshake; the offline negative control reproduces that failure mode.

The fix is limited to `tools/package-extension.mjs`: the three packaged HTML pages load the Twitch helper as a synchronous classic script before their modules. The source HTML under `public/` stays unchanged, preserving the provider-free local demo. The packaging check verifies script order, and the bootstrap fixture reproduces the old delayed-helper failure as a negative control.
